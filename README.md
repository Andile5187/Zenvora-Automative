# Zenvora Automotive

Static automotive dealership website with multiple HTML pages and shared styling.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000/Home.html

## Files

- `Home.html` — landing page
- `About Us.html` — company background
- `Services.html` — services offered
- `Showroom.html` — gallery and video showcase
- `Contact Us.html` — contact form and details
- `css/StyleSheet.css` — shared styling
- `images/` — media assets
